# Loghi dei provider

Metti qui i loghi (SVG consigliato, oppure PNG/WebP quadrati) con il nome indicato
nel campo `logo` di `src/main/config/providers.ts`, ad esempio:

- `studio-marla.svg`
- `gmail.svg`, `outlook.svg`, `icloud.svg`

Se un file manca, la griglia mostra un monogramma colorato (`monogram` + `color`).
